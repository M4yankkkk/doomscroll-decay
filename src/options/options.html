Doomscroll Decay

The longer you scroll, the more the page rots. Time counts only while a feed tab is visible and you've scrolled in the last 30 seconds.

Feed sites

Subdomains are included, so reddit.com also covers old.reddit.com. Adding a site asks Chrome for permission to run on it.

    Decay schedule

    Minutes of active scrolling per day before each stage begins. Every effect eases in between stages, so nothing switches on all at once.

      Everything is stored locally in your browser. This extension makes no network requests. Saved
